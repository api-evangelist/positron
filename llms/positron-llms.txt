## APIs

- [Positron Olivaw OpenAI-Compatible Inference API](https://support.positron.ai/api-documentation): List models, retrieve a model, create chat completions and text completions against models loaded on Positron hardware. API key in the `authorization` header. 4 operations.
- [Positron Olivaw Admin API](https://github.com/positron-ai/admin-api-docs): Control plane for the model catalogue, service nodes (Giskard / vLLM / OpenAI backends), platform users and access tokens. Bearer API key. 19 operations.

## Integration notes

- The inference API mirrors OpenAI's, so an OpenAI client library works by repointing `base_url`
  at a Positron endpoint and supplying a Positron key. Positron adds `top_k`, `seed` and
  `ignore_eos` to the selection settings.
- `functions` / `function_call` appear in the chat schema but the published document states the
  feature is not currently supported.
- Streaming is server-sent events (`text/event-stream`) via `stream: true`.
- Errors are OpenAI-style `{object: "error", type, message}` — not RFC 9457 problem+json.
- No idempotency keys, no pagination, no rate-limit headers and no published quotas.
- Positron ships no first-party SDK, no CLI, no MCP server, no webhooks/AsyncAPI, no status page,
  no public pricing and no /.well-known/ documents (all probed 2026-08-02).
